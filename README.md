# AIM ARENA

This is a game where you can practise you aiming skills in a 3d shooter kind of game.

# How to Install:
**Method 1:**
Go to [AIM ARENA](https://tharunvigneswar.itch.io/aim-arena) website to download the .exe file and run it in your computer.

**Method 2:**
Go to the releases page of this github repo to find a zip file containing the .exe file required to run this game.

# How to import game code:

1. Download Godot (https://godotengine.org/download/windows/)
2. Clone the repo using, **git clone https://github.com/TharunVigneswar/Aim-Arena.git**
3. Open Godot -> Project manager -> Import -> select the project.godot file in the repo folder
4. Press F5 or the play button to run.

# How to play:
1. Once you install the game it will show a start screen, press start.
2. Select whichever mode you want.
3. Then select the time you want to play for.
4. Then you can start playing the mode you selected and the amount of time you selected.
5. Once you are done playing, you can see your game stats and you can play again.
To control the music and sfx voulme, navigate to the main menu and press settings button, you can then change the volumes.

# Controls:
WASD to move
Mouse to aim and shoot
SPACE to jump
ESC to unlock mouse

Good luck, Have fun. Enjoy the game.

**Incase of any bugs just let me know**
